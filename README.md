# 이다솔 · Portfolio

금융서비스 기획과 UX 디자인 포트폴리오. Pretendard, 흑백과 청록색(#00A3B6)을 사용한 반응형 정적 사이트입니다.

## 로컬 확인

Node.js가 있는 환경에서 `node preview.cjs`를 실행하고 출력되는 로컬 주소를 엽니다.

## GitHub Pages

이 폴더의 파일을 저장소 루트에 올린 후 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. 별도의 빌드와 패키지 설치는 필요하지 않습니다. 상대경로를 사용해 프로젝트 저장소 주소에서도 동작합니다.

## 수정

- `index.html`: 소개, 경력, 학력, 수상
- `app.js`: 프로젝트 목록과 사례별 상세 내용
- `style.css`: 반응형 레이아웃과 디자인
- `assets/`: 최적화한 화면 이미지 및 폰트

운영 지표 원본, 개인 연락처, 지원서·증명서 등은 포함하지 않습니다. 금융 화면은 과거 작업을 설명하는 자료이며 현재 상품 조건을 안내하지 않습니다. 현대카드 프로젝트는 내부 검토 기획안으로 구분합니다. 브랜드 및 서비스의 권리는 각 권리자에게 있습니다.
